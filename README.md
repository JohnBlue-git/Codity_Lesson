# Codility Lessons

This repository contains study notes and algorithm solutions for the Codility lesson series, with implementations and explanations in both Python and C++.

The goal is to practice algorithmic thinking, improve problem-solving skills, and document solutions in a structured way while progressing through the official Codility lessons.

## Repository structure

- [Python/](Python/) — lesson notes and Python solutions
- [C++/](C++/) — C++ implementations

Each file is named by lesson, for example:

- `codility-lesson1-iterations.md` / `.cpp`
- `codility-lesson2-arrays.md` / `.cpp`
- `codility-lesson17-dynamic_programming.md` / `.cpp`

## Notes

- The Python folder focuses on conceptual explanations and reference implementations.
- The C++ folder contains matching solutions in C++ for the same lesson topics.
- This repo is intended as a learning archive and reference for Codility-style algorithm practice.

## Typical workflow

1. Read the lesson explanation in [Python/](Python/)
2. Review the matching C++ implementation in [C++/](C++)
3. Try to solve the problem independently
4. Compare with the reference solution and complexity analysis
